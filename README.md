# madk1d — фан-сайт

Неофициальный фан-сайт исполнителя madk1d: плеер, клипы, фото, соцсети.

## Запуск локально (с сервером и стеной фанатов)
```
py app.py
```
Открыть http://localhost:8000

## Статическая версия (GitHub Pages)
```
py build_static.py
```
Готовый сайт появится в папке `dist/`. На GitHub он собирается и публикуется
автоматически при каждом `git push` (см. `.github/workflows/pages.yml`).
